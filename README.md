## Projects

### MalaysiaBulletins

A C# console application that fetches and displays various Malaysian government bulletins from the data.gov.my Open Data API.

**Features:**
- Fetches multiple types of Malaysian bulletins (weather, health, fuel prices, etc.)
- Clean architecture with Models and Services layers
- Async/await for efficient API calls
- Comprehensive error handling

**Getting Started:**
```bash
cd MalaysiaBulletins
dotnet restore
dotnet build
dotnet run
```

For more information, see [MalaysiaBulletins/README.md](MalaysiaBulletins/README.md)
